Status colors — universal, not themed

These stay constant across labradorite, opalite and jadeite. Amber means caution, red means stop — same everywhere, so users don't have to relearn the signal when the theme changes.

Floats — words that carry color, but aren't swatches

Some things aren't a hex code; they're a posture. These live in the voice, not the tokens. Named so they can't be lost — but never locked to a single color.

Float
Milk Opal
The tender, protective register. Copy about family, mom's line, the “I'd do anything for you” moments. Never a swatch. Let it float.
Float
Moonstone
Tender emphasis. Earnest, unpretentious. Reserved for small joyful highlights — the “I'd marry you with paper rings” moments in copy.
Float
The Aha Moment
The brand's verb. When something lands for someone whose brain doesn't usually get that feeling, that's the aha moment. Lives in headers and product copy, not in a color.
Float
Hummingbird
Project Jadeite's precious-moment emblem. Small, fast, almost-missed. If you're tempted to use it for decoration, don't.
